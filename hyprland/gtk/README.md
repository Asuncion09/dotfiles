# GTK Settings

Configuración base para GTK 3 y GTK 4 con soporte para el tema oscuro de Adwaita y el set de iconos dinámico de Matugen.

## 🚀 Instalación

```bash
mkdir -p ~/.config/gtk-3.0 ~/.config/gtk-4.0
cp settings.ini ~/.config/gtk-3.0/settings.ini
cp settings.ini ~/.config/gtk-4.0/settings.ini
```
